# مؤسسة أول نسخة لمكافحة الحشرات بالرياض

موقع مستقل مبني على تصميم الريان السينمائي (أسود/ذهبي)، مع استخدام الصور الثلاث المقدمة وهوية المؤسسة.

## البيانات
- الاسم: مؤسسة أول نسخة لمكافحة الحشرات بالرياض
- هاتف وواتساب: 0596085101
- العرض: خصم 45% (دون افتراض شروط أو مدة)
- الفوتر: جميع الحقوق محفوظة © 2026 | شركة أول نسخة لمكافحة الحشرات
- مواعيد العمل: يوميًا من 8 صباحًا إلى 11 مساءً
- العنوان: الرياض- حي النهضة

## النشر على Render
- النوع: Static Site
- المستودع: مستودع **جديد مستقل** عن `alrayyan-ovens-jeddah` و`alrowad-sofa`
- Branch: `main`
- Build command: `echo ready`
- Publish directory: `./`

## الخصوصية والملفات
- لا يحتوي الموقع على TikTok Pixel أو Events API أو أي أكواد تتبع أو رموز وصول.
- الصور في `assets/` مهيأة للويب.
- صورة قبل وبعد مادة بصرية توضيحية وليست إثباتًا موثقًا لخدمة فعلية.
- لا يوجد سعر أو ضمان أو ترخيص أو شروط للخصم مضافة من دون مصدر.
